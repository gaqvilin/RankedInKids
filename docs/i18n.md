# Språk (svenska / engelska)

All text i appen går genom `t()` i `src/lib/i18n.ts`. **Den svenska texten är nyckeln.**

```tsx
import { t } from '../lib/i18n';

<button>{t('Rapportera resultat')}</button>
<p>{t('{n} av {total} matcher klara', { n: played, total: all.length })}</p>
```

- Engelskan ligger i `src/lib/i18n/en/<område>.ts` som `{ 'Svensk text': 'English text' }` och slås ihop i `en/index.ts`.
- Saknas en översättning visas svenskan. `test/i18n.test.ts` faller om en text i `t('…')` saknar engelska,
  eller om `{platshållare}` inte är desamma i båda språken.
- Anropa `t()` **när komponenten ritas**, aldrig på modulnivå (konstanter som `TABS` håller svenska texter;
  översätt dem där de visas: `t(tab.label)`).
- Variabler: `{namn}`-platshållare, inte `${}` i nyckeln. Ental/flertal: två nycklar
  (`'1 resultat väntar'` och `'{n} resultat väntar'`).
- Text med inbäddade element delas upp: `<strong>{t('Nästa match:')}</strong> {…}`. Flytta inte om ordningen
  mer än nödvändigt.
- Datum och tid: `fmtDay`/`fmtTime` i `src/lib/format.ts` följer språket (`locale()`). `toLocaleDateString('sv-SE')`
  som används för att få `ÅÅÅÅ-MM-DD` ska vara kvar.
- Namn från Rankedin (tävlingar, klasser, banor, spelare, klubbar) översätts inte.
- Servern (`api/`) svarar på svenska. Klienten visar meddelandet med `t(meddelande)`; fasta servertexter har
  översättning i `en/server.ts`, övriga visas på svenska.
